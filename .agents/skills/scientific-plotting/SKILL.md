# Scientific Plotting & Publication Visualization Skill

This skill defines the authoritative standards, templates, and geometric algorithms for generating publication-ready scientific figures.

## 1. Core Publication Standards
* DPI: 300 DPI for all raster outputs with tight bounding box.
* Font: Clean sans-serif (DejaVu Sans, Arial, Helvetica).
* Hierarchical Grids: 10% numeric major ticks, 5% dashed intermediate lines, 2.5% dotted minor lines.
* Zero Speech Bubbles / Narrative Badges.
* Zero Qualitative Subjective Badges ([Champion], [Winner], [Top]).
* Colorblind-safe palettes (Okabe-Ito / ColorBrewer).
* Dispersion: Mean +/- 1 STD sample error bars across seeds.
* Vapnik Generalization Dynamics: OI = sum(e * max(0, L_val - L_train)).
